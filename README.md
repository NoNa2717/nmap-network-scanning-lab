# nmap-network-scanning-lab

Hello, I'm Yusda and welcome to my cybersecurity portfolio!

https://www.linkedin.com/in/yusda-usman-m-soc-sc-b8a43a184/

I am a cybersecurity student at Business College Helsinki, developing practical skills in network security, security monitoring, and threat detection.

This project documents my hands-on experience with Nmap in a controlled lab environment consisting of Kali Linux and Windows 10 virtual machines. The exercises focused on network connectivity testing, host discovery, port scanning, service enumeration, and basic TCP/UDP scanning.

Through this lab, I explored how network scanning can help identify exposed services, understand network configurations, and support the initial stages of a security assessment. I also gained experience interpreting scan results and documenting technical findings from a defensive security perspective.

I am continuously expanding my technical knowledge and practical skills as I work towards a career in cybersecurity, particularly in Security Operations Center (SOC) and information security roles.
